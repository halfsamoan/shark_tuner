# 줄 교체 기록 계약

## 범위

줄 관리 기능은 사용자가 입력한 설치일을 기준으로 줄 나이를 계산하고, 사용자가 직접 고른 30·60·90·120일 주기에 앱 안에서 점검 시점을 표시한다. 이 값은 제조사 권고나 실제 줄 상태 진단이 아니다.

흐름은 다음과 같다.

1. 홈의 `줄 교체 기록` 행에서 줄 관리 화면을 연다.
2. 설치일, 선택적 게이지 이름, 점검 주기를 저장한다.
3. 장력·게이지 추천 화면에서는 추천 세트의 게이지와 현재 `TuningDefinition.id`를 미리 채워 같은 화면으로 연결한다.
4. 홈은 `fresh`, `dueSoon`, `due`, `overdue` 상태를 문구와 색으로 함께 표시한다.

## 데이터와 개인정보

- 스키마 버전 1 JSON을 앱 전용 지원 디렉터리에 저장한다.
- 설치일은 현지 달력 날짜, 기록 시각은 UTC, 나이는 달력 일수로 계산한다.
- 기록에는 임의 ID, 설치일, 기록 시각, 선택적 게이지, 선택적 튜닝 식별자만 들어간다.
- 저장 시 임시 파일을 먼저 기록하고 바로 전 정상 파일을 `.bak`으로 보존한다. 주 파일이 손상되면 백업을 읽고, 둘 다 읽을 수 없으면 빈 기록으로 안전하게 시작한다.
- 서버 전송, 계정, 분석 SDK는 없다. 사용자는 화면에서 기록 전체를 삭제할 수 있다.

## 알림 경계

현재 구현은 홈과 줄 관리 화면의 앱 내 점검 표시다. Android/iOS 시스템 알림 권한은 요청하지 않는다. 향후 푸시 알림을 추가할 때는 저장 모델을 재사용하되 플랫폼 예약 어댑터, 권한 사전 설명, 시간대 변경, 재부팅 복구를 별도 구현하고 개인정보 문서를 다시 검토한다.

## 검증

- 지원 주기 외 값과 알 수 없는 스키마 버전을 거부한다.
- 설치 기록 순서, 달력 일수, 만기 경계, 전체 삭제 시 주기 보존을 테스트한다.
- 원자적 저장과 손상된 주 파일의 백업 복구를 테스트한다.
- 홈 만기 표시와 장력 추천 → 설치 기록 연결을 위젯 테스트한다.
