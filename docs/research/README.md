# Research snapshots

제품 계획 수립 단계에서 작성된 리서치 원문을 임시 폴더에서 보존한 스냅샷입니다. 구현 근거와 후속 검증 대상을 잃지 않기 위해 원문을 그대로 보관합니다.

- `pitch.md`: 피치 검출 알고리즘·윈도우·라이선스 조사
- `audio.md`: 모바일 오디오 캡처·Android 입력 소스 조사
- `synthesis.md`: 전체 아키텍처 종합안
- `tension.md`: 장력 공식·게이지 추천 조사
- `ux.md`: 페그 방향·안정성 진단·접근성 조사
- `data/songs/research-starter-list.md`: 곡 라이브러리 후보와 데이터 정책 조사

이 문서의 외부 사실과 링크는 조사 시점 기준이며, 코드나 출시 데이터로 승격하기 전에 공식 출처를 다시 확인해야 합니다. 특히 곡 후보는 검증 상태가 아니라 큐레이션 대기열입니다.
