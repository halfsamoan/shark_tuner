# 장력·게이지 추천 계약

toauner의 추천은 사용자의 현재 현에서 느끼는 장력을 기준 프로필로 만든 뒤, 곡의 목표 튜닝에서도 비슷한 장력이 되는 기성 게이지 세트와 현별 맞춤 조합을 계산한다. 숫자만으로 특정 제품의 촉감이나 음색을 보장하지 않는다.

## 계산 모델

- 장력은 `T = UW × (2 × L × F)² / 386.4`로 계산한다.
- `T`는 lbf, `UW`는 lb/in 단위중량, `L`은 inch 스케일 길이, `F`는 Hz다.
- plain 강선은 지름과 강철 밀도 0.285 lb/in³로 단위중량을 유도한다.
- wound 현은 니켈 라운드와운드만 지원한다. Stringjoy 공식 공개 계산기의 선택된 측정값으로 만든 프로젝트 고유의 구간 로그 보간 모델을 사용한다.
- wound 모델은 `.018`–`.080` 범위 밖으로 외삽하지 않는다. 베이스 현이나 `.080` 초과 기타 현은 별도 모델 전에는 추천하지 않는다.
- 모델 ID는 `stringjoy-nickel-roundwound-log-fit`, 버전은 1, 확인일은 2026-07-14다. 메타데이터는 `UnitWeightModelMetadata`에 함께 저장한다.

공식 계산기가 표시하는 0.1 lbf 반올림 결과 20개를 독립 골든으로 저장했고, 모델 출력은 각 항목에서 3% 미만이다. 이는 해당 기준 모델과의 재현 오차이지 모든 제조사 제품에 대한 정확도 주장이 아니다.

## 추천 순서

1. 사용자가 현재 쓰는 튜닝·게이지·스케일로 현별 기준 장력을 계산한다.
2. 곡의 목표 튜닝에서 같은 스케일과 각 후보 세트의 장력을 계산한다.
3. 기준 장력과의 현별 제곱 오차를 합산하되 가장 낮은 현에 1.6배 가중치를 둔다.
4. `floppy` 현에는 큰 벌점을 주고, 너무 높은 장력에도 별도 벌점을 준다.
5. 저튜닝에서 수학 점수만으로 지나치게 얇은 저음을 고르지 못하도록 가드레일을 적용한다.
6. 점수가 낮은 기성 조합 3개와 현별 목표 단위중량을 역산한 맞춤 단품 조합을 함께 표시한다.

기본 기준은 25.5″, E Standard, 10–46이다. 사용자는 24.75″/25.5″/26.5″/27″/28″ 스케일과 현재 게이지를 바꿀 수 있다. 사용자 입력은 높은 줄에서 낮은 줄 순서이며 3번 줄의 plain/wound 구성을 따로 선택할 수 있다.

## 상태 구간과 가드레일

- plain `12 lbf` 미만, wound `14 lbf` 미만: `느슨`
- 해당 하한부터 `22 lbf`까지: `적정`
- plain `24 lbf`, wound `28 lbf`까지: `단단`
- 그보다 높음: `과함`
- 6현 Drop C 이하: 최저현 `.056` 미만에 벌점
- 6현 Drop A 이하: 최저현 `.062` 미만에 벌점, 26.5″ 미만이면 스케일 주의 표시
- 7현 Drop A 이하: 최저현 `.059` 미만에 벌점
- 8현 F♯1 이하: 최저현 `.065` 미만 또는 26.5″ 미만에 벌점

이 구간은 절대적인 좋고 나쁨이 아니라 v1 기본 감각 분류다. 연주 스타일, 피킹 강도, 코어 비율, 권선 재료, 새들 보정 때문에 같은 게이지도 다르게 느껴질 수 있다. 안정성 진단과 결합할 때도 `느슨` 관측과 피치 오버슈트를 함께 보여줄 뿐 원인을 단정하지 않는다.

## UI 계약

- 곡 상세에서 `이 튜닝에서 장력 확인`으로 진입한다. 라이브 튜너 화면에는 추천 UI를 넣지 않는다.
- 결과는 순번이 있는 세로 섹션과 현별 표로 표시한다. 동일한 카드 그리드를 반복하지 않는다.
- 각 현은 음, 게이지, plain/wound, lbf, 상태를 텍스트로 표시한다. 색만으로 상태를 전달하지 않는다.
- 계산 모델과 한계는 결과 화면에서 항상 확인할 수 있어야 한다.
- 상업 브랜드명보다 `11–56 드롭` 같은 일반 명칭을 우선한다. 제품 제휴나 동일 촉감을 암시하지 않는다.
