# 페그 방향 안내 계약

toauner의 페그 안내는 목표 음정에 도달하기 위한 `조이기`/`풀기`와 사용자가 실제로 돌리는 `시계방향`/`반시계방향`을 분리한다. 기타의 물리 구성을 모를 때는 전자만 표시하며, 확인되지 않은 회전 방향을 추측하지 않는다.

## 관찰 기준

- 모든 시계·반시계 표기는 **헤드스톡 앞면을 정면에서 본 사용자 시점**이다.
- 줄 번호는 일반 기타 표기대로 가장 가는 줄이 1번이고 가장 굵은 줄이 마지막 번호다.
- 프로필은 현 수, 페그 배치, 오른손/왼손, 일반/리버스 헤드스톡을 저장한다.
- 6현뿐 아니라 7·8현에서도 같은 데이터 모델을 사용한다. 분리형은 낮은 줄 쪽 페그 수를 명시하고, 인라인은 모든 페그를 같은 쪽으로 취급한다.

## 기본 진리표

수직 포스트와 표준 감김을 기준으로 음을 올리는 방향은 다음과 같다.

| 페그 위치 | 오른손·일반 | 왼손 또는 리버스 중 하나 | 왼손+리버스 |
|---|---|---|---|
| 낮은 줄 쪽 | 반시계 | 시계 | 반시계 |
| 높은 줄 쪽 | 시계 | 반시계 | 시계 |

역감김 현은 결과를 한 번 더 뒤집는다. 왼손, 리버스, 역감김처럼 방향을 뒤집는 조건의 개수가 홀수면 기본 결과의 반대이며 짝수면 기본 결과를 유지한다. 이 규칙은 `packages/tuner_domain/test/peg_guidance_test.dart`의 진리표 테스트로 고정한다.

클래식 슬롯형 롤러는 구조와 줄 감김 상태에 따라 겉으로 보이는 노브 방향을 안전하게 일반화할 수 없다. 따라서 각 페그를 시계방향으로 아주 조금 돌려 피치 변화 방향을 한 번 관찰한 뒤에만 해당 현의 회전 방향을 표시한다.

## 런타임 안전 절차

1. 현재 센트 값을 기준값으로 저장한다.
2. 사용자가 `방향 확인`을 누르고 안내 방향으로 아주 조금 돌린다.
3. 같은 줄을 다시 튕겨 최소 2 cents 이상 움직인 경우에만 결과를 평가한다.
4. 예측과 일치하면 모순 횟수를 초기화한다.
5. 예측과 반대 결과가 연속 두 번 나오면 방향 안내를 즉시 멈춘다.
6. 사용자가 승인한 경우에만 해당 페그의 방향을 뒤집어 저장한다. 다른 현의 규칙은 바꾸지 않는다.

명시적인 확인 동작을 요구하는 이유는 피킹 직후의 오버슈트와 자연 감쇠 드리프트를 사용자의 페그 조작으로 오인하지 않기 위해서다. 판단 중에는 자동으로 방향을 뒤집지 않는다.

## 저장과 표시

- 로컬 스키마는 `instrument-peg-profile.v1.json`이며 Flutter의 application-support 디렉터리에 저장한다.
- 저장 항목은 물리 프로필과 현별 감김/방향 예외뿐이다. 곡이나 튜닝 프리셋에 회전 방향을 복제하지 않는다.
- 저장 문서가 없거나 손상됐거나 현재 튜닝의 현 수와 다르면 안전 폴백으로 돌아간다.
- 튜너의 주 안내와 페그 정보는 하나의 안내 슬롯을 공유한다. 별도 카드나 고정 높이 패널을 추가하지 않는다.
- 색만으로 방향을 구분하지 않고 `↻ 시계방향`, `↺ 반시계방향` 기호와 텍스트를 함께 표시한다.

## 검증 범위

- 도메인: 3+3, 인라인, 7현 비대칭 분리형, 왼손, 리버스, 클래식 미확정, 범위 오류.
- 앱: 프로필 직렬화, 손상/미지원 버전 거부, 설정 후 물리 방향 표시, 두 번 모순 시 정지, 승인한 현만 반전, 클래식 현별 교정.
- 실물 검증: 대표 3+3, 6인라인, 왼손 또는 리버스, 클래식 기타로 화면 예측과 실제 피치 변화가 일치하는지 확인한다. 자동화 테스트가 실물 검증을 대체하지 않는다.
