# toauner UI 개선 계획 (실기기 스크린샷 8장 · 5개 UX 렌즈 리뷰 종합)

이 문서는 UI 구현의 우선순위와 알고리즘 스펙이다. 디자인 규범은 `docs/design-playbook.md`, UX 근거는 `docs/research/ux.md`.

**종합 진단**: "곡을 아는 튜너" 논지는 잘 구현됨. 그러나 튜너의 3대 핵심 피드백(방향 안내 / 인튠 완료 순간 / 현별 진행 상태)이 전부 부재하고, DSP 텔레메트리·파이프라인 문구가 화면 절반을 차지. 이 상태로는 M1 목표(비기타리스트 6현 90초) 측정이 오염된다.

**디자인 방향(사용자 확정)**: 리눅스 터미널 미학은 의도된 디자인 언어 — "터미널처럼 보이고, 악기처럼 반응하고, 소비자 제품처럼 말한다." 고칠 것은 형식이 아니라 내용이다.

## 구현 현황 (2026-07-14)

- P0 핵심 수직 조각과 P1의 자동 현 전환·잘못된 현 피드백·마이크 프라이밍·wakelock·TalkBack 라이브 리전을 구현했다.
- M2A 1차를 구현했다. 3+3/인라인/7·8현 분리형, 오른손/왼손, 일반/리버스 프로필을 저장하며, 클래식 슬롯형은 현별 관찰 전 방향을 추측하지 않는다.
- 페그 방향은 기존 튜닝 안내 슬롯 안에서만 표시한다. 예측과 반대인 피치 변화가 두 번 확인되면 안내를 멈추고, 사용자 승인 후 해당 페그만 뒤집는다. 세부 계약은 `docs/peg-guidance.md`를 따른다.
- M2B를 구현했다. 곡 상세에서 전용 장력 설계 화면으로 이동하며 스케일·사용자 게이지·상위 3세트·현별 lbf·floppy 경고·맞춤 단품 조합을 계산한다. 세부 계약은 `docs/tension-recommendation.md`를 따른다.
- 다음 UI 통합 순서는 M2C 안정성 진단 → 접근성/실기기/Figma 대조다.

## P2 — M2 이후 (차별화 기능 UI 통합)

- **M2A 페그 화살표**: P0-1 텍스트 슬롯을 헤드스톡 곡선 화살표로 대체(온보딩 데이터 기반), 텍스트는 폴백/TalkBack 유지
- **M2B 장력/게이지**: 곡 상세 "현재 튜닝과의 차이" 카드에서 확장. 튜너 화면엔 넣지 않음
- **M2C 안정성 진단**: 락 직후 칩 핍 품질 표시 + 완료 시트 진단 카드. 튜닝 중 비방해
- 기타: 스테이지 모드, 소니피케이션, 튜닝/장르 필터(80곡 도달 시), 즐겨찾기 세트리스트

## 구현 알고리즘 (의사코드)

1. **표시 2단 스무딩**: `displayCents = ema(raw, α)`, |오차|>10c → α=0.6, 이내 → α=0.3. DSP 파이프라인 값 재사용, 표시층에서만 조정
2. **cents→미터 좌표**: `x = clamp(c,−50,+50)/50 × halfWidth`. 코스 모드 히스테리시스: 진입 |c|>55, 이탈 |c|<45
3. **색 상태 머신**: |c|≤5 그린존(750ms 유지 시 lock) / 5<|c|≤15 라임 / >15 앰버. 경계 ±1c 히스테리시스
4. **방향 텍스트 생성기**: `sign(c)` → "풀어 낮추세요/조여 올리세요" + 회전량 = |c| ÷ (plain 45c : wound 100c per 1/4바퀴) → "약 N/4바퀴"(하한 1/8, 상한 2). 현 종류는 현 번호로 추정(1~3 plain, 4~6+ wound)
5. **현 칩 상태 머신**: idle → active(auto|manual) → hearingOther(감지현≠타깃 2연속) → settling → locked → done. |c|<15 중 재할당 금지 (히스테리시스: ux.md §4)
6. **자동 진행**: lock → 750ms 셀레브레이션 → 다음 미완료 현(6→1) → 전부 done → 완료 시트 + `findPlayableWith()`
7. **햅틱**: lock=더블탭(50/50/50ms), flat=느린 펄스(600−|c|×4 ms), sharp=빠른 펄스(300−|c|×2 ms)
8. **CRT 이펙트**: 정적 오버레이 → 셰이더 스캔라인은 실기기 60fps 프로파일 통과 후. RepaintBoundary로 미터 분리

## 실행 순서

**P0-8(텔레메트리 게이팅) → P0-1/2/4(튜너 3대 피드백) → P0-3/5 → 사용성 테스트 → P0-6/7 → P1**

크리티컬 스톱갭 3종(바로 튜닝 버튼·방향 텍스트·락+자동 전환)은 소~중 노력 — M2A를 기다릴 이유 없음. 이 셋이 없으면 M1 종료 기준(비기타리스트 90초) 측정 자체가 무의미하다.

## Verification

- P0 완료 후 실기기 스크린샷 재촬영(`reports/device/`) → 화면별 목표 상태·피그마 프레임과 대조
- 릴리스 플레이버 문자열 감사 테스트 통과 (파이프라인 어휘 0건)
- 비기타리스트 사용성 테스트(90초 지표)는 P0-8 완료 후에만 유효
- TalkBack 워크스루, 폰트 스케일 1.3x, 그레이스케일 스크린샷 확인 (`docs/design-playbook.md` §11 체크리스트)
