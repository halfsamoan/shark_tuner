# 6현 전체 튜닝 사용성 프로토콜

## 목표

기타를 연주하지 않는 참가자가 toauner의 곡 검색 결과에서 정밀 튜너로
들어간 뒤, 여섯 개 개방현을 모두 잠그는 데 걸리는 시간의 중앙값이
90초 이하여야 한다. 이 수치는 자동 테스트로 대체하지 않고 실제 사람
관찰값으로만 판정한다.

## 준비

- 삼성 Android 실기기 한 대와 정상 상태의 6현 통기타 또는 일렉기타.
- 참가자 최소 5명 또는 서로 독립적인 초보자 시도 최소 5회.
- 테스트 곡은 E standard의 검증 곡으로 고정한다.
- 시작 전 기타의 각 현을 ±15~30 cents 범위에서 무작위로 벗어나게 하고,
  현이 끊어질 위험이 있는 과도한 sharp 방향은 피한다.
- 참가자에게는 개방현을 하나씩 튕기고 화면 안내를 따르라는 한 문장만
  제공한다. 시험 중 조작 방법을 추가로 가르치지 않는다.

## 시간 경계

시작은 곡 상세 화면의 `이 곡으로 튜닝` 버튼을 누른 시각이다. 정밀 튜너
화면의 `튜닝 진행` 행은 최초 화면 진입부터 시간을 재고, 물리 현별 첫
`in-tune` 잠금을 한 번씩만 센다. `6/6 · 완료 mm:ss`가 나타난 시각을
종료로 기록한다. 뒤늦게 현이 풀려도 이미 완료한 시도의 시간은 바꾸지
않는다.

## 기록

각 시도마다 참가자 ID, 기타 종류, 줄 상태, Android 모델, 앱 커밋,
선택 곡, 완료 시간, 잘못된 현 선택 횟수, 도움 요청 여부를 기록한다.
미완료는 180초에서 중단하고 실패로 기록한다. 완료 시간들을 오름차순으로
정렬해 중앙값을 계산하며, 짝수 개 시도라면 가운데 두 값의 평균을 쓴다.

합격 조건은 중앙값 90초 이하이고 잘못된 현 안내로 인한 안전 문제가
0건인 경우다. 결과는 날짜가 포함된 `docs/usability-results-*.md`에
원자료와 함께 저장한다.
