# 튜닝 기록 계약

## 기록 시점

- 활성 `TuningDefinition`의 모든 물리 현이 처음 잠긴 순간 한 세션을 한 번만 기록한다.
- 같은 잠금 프레임이 반복되거나 완료 시트를 다시 열어도 중복 기록하지 않는다.
- 중간에 화면을 나가거나 일부 현만 맞춘 세션은 기록하지 않는다.

## 저장 필드

- 완료 UTC 시각, 전체 소요 시간, 현 수
- 튜닝 ID·버전·표시 이름
- 곡에서 시작했다면 곡 ID·제목·아티스트
- 오디오 원본, 주파수 프레임, 센트 시계열, 마이크 입력 경로는 저장하지 않는다.

## 로컬 보관과 삭제

- `tuning-history.v1.json`과 마지막 정상 백업을 앱 전용 지원 디렉터리에 저장한다.
- 최신 순으로 최대 100회 보관한다.
- 홈 헤더의 `LOG`에서 조회하고 화면의 `전체 삭제`로 즉시 비운다.
- 저장 실패는 라이브 튜닝과 완료 UI를 막지 않는다.

## 회귀 게이트

- 코덱 왕복, 손상 백업 복구, 동시 append 직렬화, ID 중복 제거, 100회 상한을 테스트한다.
- 6현 완료 위젯 테스트에서 곡·튜닝 메타데이터가 한 번만 기록되는지 확인한다.
- 360×780 홈에서 곡 검색 결과를 화면 밖으로 밀지 않도록 기록 진입점은 추가 카드가 아닌 헤더 계기판 액션을 사용한다.
