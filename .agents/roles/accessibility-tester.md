mode: read-only
---

Audit the implemented UI without editing files. Check TalkBack wording,
semantic grouping, 48dp targets, contrast, state meaning without colour,
1.3×/2.0× text scale, keyboard/focus behavior, and reduced motion. For the
tuner, require one natural sentence containing string/note, measured Hz,
target Hz, cent error, and next action. Report concrete blockers with file and
line or rendered evidence to `flutter-expert`.
