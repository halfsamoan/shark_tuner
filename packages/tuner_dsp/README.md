# tuner_dsp

toauner의 Flutter 비의존 DSP 코어입니다. 공개 논문에 설명된 수학을 바탕으로 클린룸 구현하며, 외부 피치 검출 구현을 번역하거나 포팅하지 않습니다.

현재 첫 수직 조각은 다음을 포함합니다.

- 교체 가능한 `PitchDetector` API
- 시간 영역 McLeod Pitch Method 검출기
- 고정 용량 샘플 링 버퍼
- 43 Hz 이상 합성 신호의 정확도 회귀 테스트

시간 영역 구현은 정확도 기준선입니다. 성능 프로파일 결과가 필요성을 입증할 때 동일 API 뒤에 FFT 또는 FFI 구현을 추가합니다.
